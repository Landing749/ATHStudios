how it goes

Show the card, get marked.

The teacher opens ATSYS with the class’s SF2 loaded. Learners come in and show their cards. The app reads the code, finds the learner, marks Present or Late under today’s date, and saves the file.

There is no second database to reconcile at the end of the month. The SF2 is the record, and ATSYS writes straight into it.

Old PCs, slow antivirus, locked files.

ATSYS was built for school-issued hardware. This is what it does when things go wrong.

If this happensATSYS does this
Excel won’t save?Every scan goes into a Scan Journal first, so the attendance is never lost.
No internet?Scanning, marking and saving carry on. Licensing and sync catch up later.
Wrong file imported?The file is checked before anything is touched. If the swap fails, your previous file is put back.
PC acting strange?A built-in diagnostic console has logs and a self-test, so a problem can be investigated without installing anything.
