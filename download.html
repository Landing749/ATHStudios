01

Installing it

1

Download the file

Click the download button above. Your browser will save InkResetTool.exe to your Downloads folder.

2

Allow it through your browser's check

Chrome or Edge may flag the file as unrecognized since it isn't signed with a paid certificate. Choose Keep or Keep anyway when prompted.

3

Get past Windows SmartScreen

Windows will likely show a blue "protected your PC" screen the first time you run it. This is expected for independently published tools — see the section below for exactly what to click.

4

Connect your printer and run

Make sure your printer is connected via USB and powered on, then launch InkResetTool.exe. Select your model and follow the on-screen steps.

More info

You'll very likely see this. It's not a virus warning — it just means the .exe hasn't been signed with a paid Microsoft-verified certificate, which every small, independently distributed Windows tool runs into. Here's what to do:

1. Click More info in the blue window.

2. A Run anyway button will appear at the bottom — click it.

3. InkResetTool will open normally. This only happens the first time you run this specific file.

Antivirus flags: some antivirus tools may also flag it for the same reason — it isn't from a recognized publisher, not because it contains malware. If you'd rather verify first, scan the file on VirusTotal before running it.
